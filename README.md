# Hospital Queue Management System

A simple web-based hospital queue management system built using HTML, CSS, and JavaScript.  
It allows users to book appointments, view live queue status, and cancel bookings in a structured workflow.

---

## Features

- Select hospital and department
- View current queue before booking
- Book appointment and generate token number
- Automatic estimated consultation time based on queue position
- Cancel appointment using hospital, department, and token number
- Pre-loaded sample patient data for realistic simulation
- Simple receipt generation after booking

---

## How It Works

1. The user selects a hospital and department.
2. The system displays the current queue length and patient list.
3. On booking:
   - A unique token number is generated
   - Estimated consultation time is calculated
   - The patient is added to the queue
   - A receipt is displayed with all details
4. For cancellation:
   - The user selects hospital, department, and enters the token number
   - The system removes the patient from the queue if found

---

## Technology Stack

- HTML for structure
- CSS for styling
- JavaScript for application logic and queue management
